গুরুত্বপূর্ণ:
1) WPAY merchant dashboard-এ শুধু User Service-এর Callback URL বসাবেন। Admin Service-এ WPAY Callback দেবেন না।
2) দুই Render service-এ একই Firebase project/service account এবং একই RTDB URL থাকতে হবে।
3) User Server-এর deposit minimum এখন 500 টাকা এবং maximum 50000 টাকা। User HTML-এ UI-র min/max আলাদা থাকলে মিলিয়ে নেবেন।
4) Admin withdrawal approval-এ Admin-কে আগে নিজে ইউজারকে টাকা পাঠাতে হবে। তারপর Approve করবেন। Approve-এ wallet থেকে amount কাটা হয়; WPAY ব্যবহৃত হয় না।
5) Admin password reset শুধু users/{phone}/authUid থাকলে Firebase Authentication password বদলাবে। বর্তমান SPL user login-এ plaintext users/{phone}/password ব্যবহৃত হচ্ছে এবং registration সরাসরি browser থেকে RTDB-তে user তৈরি করছে। তাই পুরোনো ইউজারদের password reset নিরাপদভাবে চালু করতে Firebase Authentication migration ও login/register পরিবর্তন প্রয়োজন। বর্তমান প্যাকেজ legacy password plaintext field বদলায় না।
6) Registration bonus/minimum withdrawal সেটিং Admin UI থেকে site_settings-এ সেভ হয়। কিন্তু বর্তমান registration bonus browser-side code-এ যোগ হয়; নিরাপত্তার জন্য registration/bonus grant trusted backend-এ স্থানান্তর করা প্রয়োজন।
7) Admin HTML-এর বেশিরভাগ কাজ সরাসরি Firebase SDK ব্যবহার করে। Firebase RTDB Rules-এ Admin UID authorization এবং user data access সীমাবদ্ধ না থাকলে Admin controls নিরাপদ হবে না। Rules না দেখে এখানে কোনো নতুন Rules বসানো হয়নি।
8) WPAY signature field, status value এবং amount field merchant-এর বর্তমান API specification দিয়ে বাস্তব test transaction-এ নিশ্চিত করুন। Code-এর `status=1` বা `success` acceptance provider spec-এর সঙ্গে মিলতে হবে।
9) আগের 24-hour income/earning logic-এ ইচ্ছাকৃত পরিবর্তন করা হয়নি। Live RTDB/Render access না থাকায় production test করা সম্ভব হয়নি।

Deploy-এর আগে বর্তমান ফাইল ও Firebase database-এর backup নিন।


নতুন পরিবর্তন:
- Registration bonus backend থেকে site_settings/registration_bonus পড়ে; Admin Panel-এ 50 থেকে 150 করলে পরের নতুন registration-এ 150 টাকা এবং User Panel-এর registration text-ও 150 দেখাবে।
- WPAY verified deposit সফল হলে deposit amount-এর ওপর Level 1/2/3 referral commission site_settings/referral_commission_rates অনুযায়ী credit হবে; default 10%, 2%, 1%। Manual Admin-approved deposit-ও একই commission logic ব্যবহার করে।
- Package purchase-এ duration, next payout, total earned এবং earning count সংরক্ষণ হয়। প্রতি 24 ঘণ্টায় backend worker wallet-এ daily income credit করে এবং earningLogs লেখে।
- Withdrawal request শুধু Admin Panel-এ review হয়। Approve করার আগে Admin বাইরে থেকে bKash/Nagad-এ টাকা পাঠিয়ে তারপর Approve করবে; WPAY payout ব্যবহার হয় না।
- User earning page-এ daily income, total earned, last payout এবং next payout দেখায়।
- User Panel-এ registration bonus এবং marquee text site_settings থেকে live update হয়। editable_texts দিয়ে ID-based text override করা যায়।


নতুন ফিচার: Admin > Deposits থেকে MANUAL DEPOSIT দিয়ে কোনো ইউজারের ব্যালেন্সে ডিপোজিট সাথে সাথে Approved হিসেবে যোগ করা যাবে। Admin > Site Settings > Common User Texts থেকে Withdraw/Register-এর সাধারণ লেখা বদলানো যাবে।
